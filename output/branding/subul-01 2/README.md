# Subul Technology — Direction 01

Approved direction: ascending pathways / S monogram.

- logo-primary: teal symbol and navy lettering; transparent.
- logo-reversed: white artwork; transparent.
- logo-on-navy: white artwork on navy.
- logo-monochrome: single navy color.
- symbol-teal / symbol-white / symbol-navy: independent mark.
- social-avatar: teal mark on navy, square.
- favicon.ico: multiple sizes, 16–256 px.

SVG files contain outlined text and require no installed fonts. PNG files are exported at 2× SVG dimensions with transparency where appropriate.

Colors: teal #36ADA3; navy #0B0F1F; light #F7F9FC.
Clear space: at least 20% of symbol height. Suggested starting minimums: full bilingual lockup 240 CSS px wide / 45 mm printed; use symbol alone below that. Verify on actual print stock before production.

The raster concept was reconstructed as vector geometry and typeset with Arial and Geeza Pro outlines; this is a refined interpretation, not an automatic trace. No website assets were replaced. Print vendor should convert to its required CMYK profile.
